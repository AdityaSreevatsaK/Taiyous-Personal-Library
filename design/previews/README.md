# Taiyou's Personal Library: UI exploration

Three self-contained, dependency-free **design concepts** for review before implementation in the real React application. The production application and private novel dataset are untouched.

## Concepts

| Design | Direction | Why consider it |
| --- | --- | --- |
| **The Jade Archive** | Dark jade, polished brass, premium literary typography, prominent current book | Rich and personal, suited to cultivation-heavy reading |
| **Paper & Ink** | Warm ivory, walnut/burgundy accents, magazine-like editorial hierarchy | Calm for long reading sessions while retaining meaningful metadata |
| **Midnight Atlas** | Deep blue, amber, restrained navigational chrome | Contemporary and information-dense without a busy dashboard |

## Preview

Open [index.html](index.html) locally in your browser. Switch the three design selectors above the prototype. Test the bookshelf, filter tabs, a novel detail page, the reading view, chapter buttons and phone-sized layout. Data is synthetic and never uploaded.

This is a **standalone prototype**, not production code. Colours, component hierarchy and typography are exploratory. No private collection data, authentication, persistence, or real EPUB files are included. The final implementation should retain the real application's Owner-mode protections, scroll-only chapter reading, offline caching, routing, tag editing and conflict-safe cloud sync.

## Online design references

- [Tome](https://tome.bndct.sh/): custom shelves and a compact book-first dashboard
- [PageBack](https://pageback.app/): prominent continue-reading feature and browsing hierarchy
- [Margin Reader](https://www.marginreader.com/): calm book reading and chapter contents
- [Koodo Reader](https://koodoreader.com/en): adaptable typography and different devices
- [Bookshelf design case study](https://www.behance.net/gallery/246245337/Bookshelf-Personal-Reading-Dashboard): warm dark library styling

These sources inform interface principles only. The prototype uses original code and synthetic cover graphics.

**Do not merge** this design branch or deploy its interface without choosing a direction and reviewing the real app's screens, mobile layout and accessibility.
